# Contributing

MetaDerm-CBM is a research codebase accompanying an academic manuscript.

When contributing:

1. Do not modify frozen publication results without documenting the reason.
2. Do not tune models or thresholds on PH².
3. Add tests for changes to inference, reasoning, calibration, or metacognitive logic.
4. Keep datasets and restricted patient images outside version control.
5. Clearly label prototype features that were not part of the validated manuscript experiments.
6. Use pull requests for substantive changes after the first public release.
