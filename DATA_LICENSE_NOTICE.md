# Dataset licensing notice

This repository intentionally does **not** contain or redistribute Derm7pt images or the original dataset package.

Users must obtain Derm7pt from the official dataset provider and comply with the provider's license and citation requirements. The code assumes a local path to an authorized copy of the dataset.

Derived experiment outputs should not contain original images unless the user's authorization and the dataset license permit such use. For a public code release, prefer numeric predictions, aggregate tables, and non-identifying plots.
